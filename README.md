| Auto-Sudoku | https://mrdadado.github.io/Auto-Sudoku/ | [MrDaDaDo/Auto-Sudoku](https://github.com/MrDaDaDo/Auto-Sudoku) |

## Adding a new game

1. Add a card for it in `index.html` (and its description in each language in the `DICT` object).
2. Add its URL to `sitemap.xml`.

The site is verified in Google Search Console as the URL-prefix property `https://mrdadado.github.io/`, which covers every project page under it, so new games do not need to be verified separately. Keep `google46671c0e696b4d44.html` in this repository.
